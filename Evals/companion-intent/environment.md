# 첫 평가 환경

Status: draft

- Live: 기존 localhost Ollama 서버와 설치된 네 모델. 한 번에 한 모델만 평가한다. 모델 설치·서버 시작·실제 앱 설정 변경은 하지 않는다.
- Frozen: 현재 시각 2026-09-18 10:00 Asia/Seoul. 사용자 메시지만 모델에 제공하고 숨겨진 기대 행동은 제공하지 않는다.
- Simulated: 조회·생성 요청의 평가용 처리기. 실제 일정 DB, 목표 DB, 대화 DB, 미리알림에는 접근하지 않는다.
- 상태: 매 시도마다 빈 평가용 일정 저장소와 요청 로그로 초기화한다. 조회 요청은 해당 날짜 목록을 반환하고 생성 요청은 검증된 제목·날짜를 평가용 저장소에만 기록한다. 이 표면은 새 평가 프로토타입이며 기존 앱 도구라고 주장하지 않는다.
- 증거: 초기/최종 일정 상태와 관찰한 요청·오류를 채점기에 제공한다. 모델은 원시 증거 파일이나 채점 파일을 읽지 못한다.
- 효과: 로컬 추론에 따른 메모리 사용과 평가 결과 파일만 발생한다. 실제 사용자 데이터 쓰기와 외부 전송은 금지한다.
- Fidelity limits: 실제 앱 UI·SwiftData·취소 경쟁·공용 모델 실행 조율·MLX·Apple 실행은 재현하지 않는다. 첫 과제 통과로 이 항목들을 검증 완료 처리하지 않는다.
